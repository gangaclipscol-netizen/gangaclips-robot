# GangaClips robot

Clips verticales de Westcol y amigos (Kick) hechos en la nube con GitHub Actions: la IA escoge los mejores momentos,
arma el clip con subtítulos, publica en Instagram @gangaclips.col + Facebook y lo manda al bot de Telegram.

- Lista de streamers: `clips/gangaclips.json`
- Corre solo todos los días a las 9 a. m. (Colombia). A mano: Actions → "GangaClips en la nube" → Run workflow.
- Las llaves van como secretos del repo, nunca en el código.
